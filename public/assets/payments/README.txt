WarQ payment brand assets
=========================

Files:
- bkash-logo.svg  — Official bKash wordmark (from https://www.bkash.com/ navbar)
- nagad-logo.png  — Official Nagad wordmark (from https://nagad.com.bd/ site assets)

Sources:
- bKash: https://www.bkash.com/
- Nagad: https://nagad.com.bd/

These files are stored locally so logos load reliably in development and production.
To refresh from the official websites, run:

  npm run export:payment-logos

Do not stretch, recolor, or modify these logos in the UI. Display them with object-fit: contain.
